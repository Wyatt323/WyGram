# WyGram 幽灵模式

入口：设置 → WyGram → 幽灵模式。四个开关各自独立，保存在当前账号的本机 Postbox 中，共用同一账号存储的扩展读取同一配置。新开关默认关闭；首次读取时将旧版本机快拍隐身选项的当前值固定为这个账号的初始值，之后不受 Swiftgram 远程功能开关控制。

- 不上报快拍浏览：拦截普通及置顶快拍的查看上报，普通快拍仍更新本机已读圆环。待同步的快拍查看操作在开启时丢弃并清理，不积压到关闭后补发。
- 不主动上报在线：当前账号请求离线，取消本机在线心跳；关闭后跟随应用原有在线状态流程。
- 不发送输入状态：拦截文字、录音、上传、贴纸选择等输入活动，包括秘密聊天的输入提示。群组通话的发言存活信号仍按原流程发送。
- 不发送消息已读状态：聊天历史（普通聊天、群组/频道、秘密聊天）、话题/讨论、本机媒体播放/消费、提及、反应/投票阅读和实时位置查看的对应回执入口受到控制。本机已读、内容消费标记和倒计时处理继续执行。被拦截的云端同步操作完成本机清理，不伪造服务端 pts，也不保持无限重试。

这不是服务端隐私设置，不能控制其他客户端，不能撤回已发出或已进入秘密聊天加密发送序列的旧回执。秘密聊天已有发送序列和重传记录保持原样；开关开启后不再为新消费事件创建内容回执，聊天历史已读同步也被拦截。

发送消息、互动或其他设备仍可能让 Telegram 显示在线。关闭隐藏已读后，后续正常阅读同步的是累计已读位置，较早的消息也可能随之显示已读。已经在服务器记录的已读或快拍浏览无法撤销。

本功能不修改对方的消息、服务端隐私规则或其他客户端，不改动现有本机消息历史、保留图片文件/读取方式、连接恢复、分享、签名或 Bundle ID。

`Tests/GhostModeProbe` 编译生产设置/策略与相关发送函数，替换账号/网络传输为记录器，使用真实 Postbox、构造账号和 UIKit 检查本机行为。它不建立 Telegram 连接，不代表真实账号双方收发或 LCSign 真机验证。1.1.5（27）起提供这些开关。
