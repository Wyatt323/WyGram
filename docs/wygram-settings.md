# WyGram 设置入口

主设置页的 WyGram 分组仅显示“WyGram”和“WyGram 在线更新”。“消息通知状态”位于 WyGram 内部的通知分组。

原 WyGram Features 发布页面中的五项功能直接合并进 WyGram：

- 实用功能：账号备份、消息过滤器、格式面板。
- 通知：置顶消息、提及和回复的通知处理选项。

账号备份和消息过滤器沿用原控制器；格式面板和通知选项继续使用原 `SGSimpleSettings` 键和通知共享同步方式。无需迁移、重置配置或重新登录。主设置内旧 Features 导航动作也指向合并后的 WyGram 页面。

幽灵模式、消息记录、系统分享与在线更新入口仍可从 WyGram 页面访问。本次仅整理入口和复用既有功能，不修改通知投递、账号存储、备份内容、消息过滤规则或品牌资源。

1.1.5（27）起提供以上合并入口。
